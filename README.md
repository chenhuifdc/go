# WhatsApp Ops - 企业级 WhatsApp 运营管理平台

> 类似 CEO 全球通、HAPPY World 的 WhatsApp 运营平台，但更强、更灵活、完全本地化部署。

## ✨ 核心功能

| 模块 | 功能 | 状态 |
|------|------|------|
| 📱 **多账号管理** | API 方式多开，每账号独立代理，二维码扫码登录，自动重连 | ✅ M1 |
| 👥 **CRM 客户管理** | 客户备注、标签、跟进记录，本地 SQLite 存储，支持导入导出 | 🚧 M3 |
| 🌐 **智能翻译** | OpenAI 兼容 API，自定义 Prompt 模板，右键/快捷键一键翻译 | 🚧 M4 |
| 📢 **群发 & @All** | 一键多群发送，支持 @全体成员强提醒，速率控制、重试机制 | 🚧 M5 |
| 🛡️ **群组管理** | 一键开关群（仅管理员/全员发言）、一键导出成员（昵称+手机号） | 🚧 M5 |
| 🔍 **三级风控** | L1 垃圾广告、L2 敏感违规、L3 行为分析（刷屏/频繁@），自动删/警/踢 | 🚧 M6 |
| ⚙️ **可视化配置** | 零构建前端，双击即用，所有设置 Web 界面可配置 | ✅ M1 |

## 🚀 快速开始

### 1. 环境要求
- **Windows 10/11** (x64)
- **Go 1.22+** (仅编译时需要，运行时单 `.exe` 无依赖)
- 可选：已安装的代理工具 (Clash/Shadowsocks/V2Ray 等)

### 2. 编译 (开发者)
```bash
cd whatsapp-ops
go mod download
go run build.go          # 内嵌前端静态文件
go build -ldflags="-s -w -H=windowsgui" -o bin/whatsapp-ops.exe ./cmd/whatsapp-ops
```

### 3. 直接使用 (用户)
1. 下载 Release 包，解压到任意目录
2. 双击 `whatsapp-ops.exe` 启动
3. 浏览器自动打开 `http://127.0.0.1:8080` (或手动访问)
4. 首次运行会生成 `config.yaml` 和 `data/` 目录

### 4. 基础配置
编辑 `config.yaml` 填入关键信息：
```yaml
translation:
  api_key: "sk-xxx"          # 必填：翻译 API Key
  base_url: "https://api.openai.com/v1"  # 可选：自定义 Base URL
  model: "gpt-4o-mini"       # 可选：模型名称

whatsapp:
  default_proxy: "socks5://127.0.0.1:7890"  # 可选：默认代理
```

> 敏感信息建议通过环境变量设置：`WAOPS_TRANSLATION_API_KEY=sk-xxx`

## 📖 使用指南

### 账号接入
1. 点击「账号管理」→「+ 添加账号」
2. 填写名称、代理 (可选，格式：`socks5://user:pass@ip:port` 或 `http://ip:port`)
3. 点击「启动」，等待二维码生成
4. 用 WhatsApp 手机端扫码登录
5. 状态变为「connected」即可使用

### CRM 客户管理
- 「CRM 客户」页：搜索、新建、编辑、标签管理、跟进记录
- 支持 CSV/Excel 批量导入，一键导出
- 标签支持自定义颜色，多标签组合筛选

### 翻译功能
- 设置页配置 API Key、Base URL、Model、目标语言
- 自定义 Prompt 模板 (支持 `{{.Text}}`、`{{.TargetLang}}`、`{{.ContactName}}`)
- 聊天界面右键消息 → 「翻译」，或选中文本 `Ctrl+T` 翻译

### 群发任务
1. 「群发任务」→「+ 创建群发任务」
2. 选择发送账号、目标群组 (多选)、输入内容
3. 勾选「@All 全体成员」触发强提醒
4. 设置发送间隔、并发数，点击「开始发送」
5. 实时查看进度、成功/失败日志，支持暂停/继续/重试

### 群组管理
- 群列表显示：名称、群主、成员数、开放/仅管理员状态
- 一键切换：仅管理员发言 ↔ 全员可发言
- 一键导出：成员昵称、手机号、是否管理员 → CSV
- 成员管理：踢人、设为/取消管理员

### 三级风控
| 级别 | 检测内容 | 处理方式 |
|------|----------|----------|
| **L1** | 广告链接、微信号、QQ号、邀请码、价格、联系方式 | 关键词/正则 + AC自动机 |
| **L2** | 政治敏感、色情暴力、赌博毒品、诈骗话术 | 词库 + 同音字变体匹配 + 可选本地模型 |
| **L3** | 刷屏(>20条/分)、频繁@(>5次/分)、重复内容、频繁进出群 | 滑动窗口统计 + SimHash 去重 |

- 「风控中心」→「管理规则」：可视化增删改查规则，支持优先级
- 「风控中心」→「管理词库」：导入/导出 L1/L2 词库 (TXT/CSV)
- 自动动作：删除消息 / 私聊警告 / 踢出群聊 / 仅记录
- 所有事件可审计、可导出、可撤销

## ⚙️ 高级配置

### 代理设置
每个账号独立代理，支持格式：
```
socks5://user:pass@127.0.0.1:7890
socks5://127.0.0.1:1080
http://127.0.0.1:7890
http://user:pass@127.0.0.1:8080
```
留空 = 直连。建议使用纯净住宅 IP 代理。

### 翻译 Prompt 模板
```go
你是专业的跨境电商翻译助手。
将以下内容翻译为 {{.TargetLang}}，保持商务礼貌语气，
专业术语保留英文，表情符号保留原样。
只返回翻译结果，不要解释。
原文: {{.Text}}
```
可在设置页实时修改，立即生效。

### 风控阈值调整 (config.yaml)
```yaml
risk:
  l3_window_size: 60           # 统计窗口(秒)
  l3_max_msg_per_min: 20       # 单分钟最大消息数
  l3_max_mention_per_min: 5    # 单分钟最大@次数
  auto_action: false           # 是否自动执行动作
  default_action: "warn"       # 默认动作: log/warn/delete/kick
```

## 🔒 安全与合规提醒

> ⚠️ **重要**：使用非官方 WhatsApp 协议存在封号风险，请务必：
> 1. **使用纯净住宅代理**，避免数据中心 IP
> 2. **控制发送频率**：单账号 ≤30条/分，群发间隔 ≥2秒
> 3. **新号预热**：前 3-7 天仅收发正常消息，不群发
> 4. **内容合规**：避免敏感词、诱导分享、过度营销
> 5. **定期备份**：`data/` 目录包含所有会话和业务数据
> 6. **合法合规**：仅用于合法业务场景，遵守当地法律法规

## ❓ 常见问题

**Q: 为什么不直接用官方 Business API？**
A: 官方 API 需要企业认证、模板审核、按对话收费、无法 @All、无法导出群成员、无法自建风控。本项目用非官方协议实现全功能，适合中小团队自建。

**Q: 会被封号吗？**
A: 非官方协议有封号风险。严格遵循「安全与合规提醒」中的建议可大幅降低风险。建议准备备用号。

**Q: 支持 Linux/macOS 吗？**
A: Go 交叉编译即可：`GOOS=linux GOARCH=amd64 go build ...`，前端零构建天然跨平台。

**Q: 如何升级版本？**
A: 替换 `whatsapp-ops.exe` 即可，数据目录 `data/` 向后兼容。

**Q: 翻译不准怎么办？**
A: 在设置页调整 Prompt 模板，或更换更强模型 (gpt-4o, claude-3.5-sonnet 等)。
